FORMA — školski projekat (HTML, CSS i JavaScript)

POKRETANJE
1. Raspakuj ZIP arhivu.
2. Otvori folder forma_website u Visual Studio Code-u.
3. Otvori index.html u browseru ili koristi VS Code ekstenziju Live Server.

STRUKTURA
- index.html       struktura i tekst sajta
- style.css        boje, tipografija, raspored i responsive stilovi
- script.js        mobilni meni, galerija/lightbox i automatska godina
- images/          fotografije korišćene na sajtu
